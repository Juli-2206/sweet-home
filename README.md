# sweet-home
Página de ventas de elementos para le hogar



| ID | Historia de Usuario | Criterios de Aceptación |
| :--- | :--- | :--- |
| **HU01** | Como usuario visitante quiero un menú de navegación claro para moverme fácilmente por el sitio. | • Menú visible en la parte superior.<br>• Navegación funcional entre secciones/páginas.<br>• Adaptación a móvil. |
| **HU02** | Como administrador del sitio quiero poder agregar, editar y eliminar productos (imagen, descripción y precio) para mantener actualizado el catálogo de Sweet Home. | • Tener una página tipo “panel” o sección de gestión donde se pueden:<br>&nbsp;&nbsp;- Agregar productos (imagen + descripción + precio).<br>&nbsp;&nbsp;- Editar productos.<br>&nbsp;&nbsp;- Eliminar productos.<br>• Los productos se reflejan en la galería principal, con validación básica de campos (no vacíos). |
| **HU03** | Como usuario quiero enviar mi carrito de compras a WhatsApp para finalizar mi compra fácilmente. | • Existe botón “Comprar” en el carrito.<br>• Se genera un mensaje automático con: Lista de productos, Precios, Total.<br>• Se abre WhatsApp con el mensaje precargado. |
| **HU04** | Como cliente quiero dejar mi propia reseña para compartir mi experiencia con otros usuarios. | • Existe un formulario de reseñas: Nombre, Comentario.<br>• La reseña se muestra en pantalla después de enviarla, se mantiene visible, no elimina testimonios existentes. |
| **HU05** | Como usuario móvil quiero que el footer se adapte correctamente para visualizar la información sin errores. | • No hay desbordamiento horizontal.<br>• Elementos del footer se reorganizan en columna.<br>• Texto legible en pantallas pequeñas.<br>• Íconos o enlaces bien alineados. |
