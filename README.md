# sweet-home
Página de ventas de elementos para le hogar

 # Historias de Usuario


# HU01	
Como usuario visitante quiero un menú de navegación claro para moverme fácilmente por el sitio.	
Criterio:Menú visible en la parte superior 
Navegación funcional entre secciones/páginas 
Adaptación a móvil

# HU02	
Como administrador del sitio quiero poder agregar, editar y eliminar productos (imagen, descripción y precio)
para mantener actualizado el catálogo de Sweet Home.	
Criterio: Tener una página tipo “panel” o sección de gestión donde se pueden:
Agregar productos (imagen + descripción + precio)
Editar productos
Eliminar productos
Los productos se reflejan en la galería principal, con validación básica de campos (no vacíos).

# HU03
Como usuario quiero enviar mi carrito de compras a WhatsApp para finalizar mi compra fácilmente.	
Criterio: Existe botón “Comprar” en el carrito
Se genera un mensaje automático con:
Lista de productos
Precios
Total
Se abre WhatsApp con el mensaje precargado

# HU04
Como cliente quiero dejar mi propia reseña para compartir mi experiencia con otros usuarios.	
Criterio: Existe un formulario de reseñas:
Nombre
Comentario
La reseña se muestra en pantalla después de enviarla
Se mantiene visible
No elimina testimonios existentes.

# HU05
Como usuario móvil quiero que el footer se adapte correctamente para visualizar la información sin errores.
Criterio: No hay desbordamiento horizontal
Elementos del footer se reorganizan en columna.
Texto legible en pantallas pequeñas
Íconos o enlaces bien alineados
